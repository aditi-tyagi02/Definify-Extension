# Definify – Instant Word Meaning Extension

Definify is a lightweight browser extension designed to make understanding unfamiliar words easier while browsing the web. It allows users to look up word meanings conveniently without interrupting their reading experience.

## Features
Quick Word Lookup: Get the meanings of unfamiliar words conveniently.

Easy Understanding: Helps users understand new words while browsing webpages.

Lightweight: Designed to provide a smooth browsing experience.

User-Friendly: Offers a simple and intuitive interface.

Browser Integration: Built using JavaScript and Chrome Extension APIs.

## Tech Stack
JavaScript – Handles the extension's core functionality.

HTML – Structures the extension's user interface.

CSS – Styles the interface for a clean user experience.

Chrome Extension APIs – Enables browser integration.

JSON – Manages extension configuration through manifest.json.

## Installation
Follow these steps to install Definify locally.

Step 1: Clone the Repository

bash
git clone https://github.com/aditi-tyagi02/Definify-Extension.git
Step 2: Open Google Chrome
Launch the Google Chrome browser.

Step 3: Navigate to Chrome Extensions
Enter the following URL in your browser:


text
chrome://extensions/
Step 4: Enable Developer Mode
Turn on Developer mode using the toggle in the top-right corner.

Step 5: Load the Extension
Click on Load unpacked.

Select the downloaded Definify-Extension folder.

Definify will now be installed and available in your Chrome browser.

## Usage
Install Definify using the installation steps.

Open any webpage in Google Chrome.

Use the extension's word-lookup functionality.

Explore word meanings without interrupting your browsing experience.
